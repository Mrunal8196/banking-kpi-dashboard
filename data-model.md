# Data Model & Data Dictionary

## Schema type
Star schema — one central fact table surrounded by conformed dimensions. Keeps DAX simple,
relationships single-directional, and refresh fast.

```
   DimDate ──┐
             ├──► FactKPIMonthly ◄── DimBranch
 DimProduct ─┘
```

| Relationship | Cardinality | Direction | Cross-filter |
|---|---|---|---|
| DimBranch[BranchID] → FactKPIMonthly[BranchID] | 1:* | DimBranch → Fact | Single |
| DimProduct[Product] → FactKPIMonthly[Product] | 1:* | DimProduct → Fact | Single |
| DimDate[Date] → FactKPIMonthly[Month] | 1:* | DimDate → Fact | Single |

---

## FactKPIMonthly (grain: branch × product × month)

| Column | Type | Unit | Description |
|---|---|---|---|
| Month | Date | — | First day of the reporting month |
| BranchID | Integer | — | FK → DimBranch |
| Region | Text | — | Denormalized region (also on DimBranch) |
| Product | Text | — | FK → DimProduct |
| Deposits_EURm | Decimal | EUR millions | End-of-month deposit book |
| Loans_EURm | Decimal | EUR millions | End-of-month loan book |
| NIM_pct | Decimal | % | Net interest margin for the month |
| InterestIncome_EURk | Decimal | EUR thousands | Interest income |
| FeeIncome_EURk | Decimal | EUR thousands | Fee & commission income |
| Revenue_EURk | Decimal | EUR thousands | Interest + fee income |
| Opex_EURk | Decimal | EUR thousands | Operating cost |
| NPA_pct | Decimal | % | Non-performing-asset ratio |
| NewCustomers | Integer | count | Customers acquired in month |
| ActiveCustomers | Integer | count | Active customers in month |
| CSAT | Decimal | 1–5 | Avg customer satisfaction |

## DimBranch

| Column | Type | Description |
|---|---|---|
| BranchID | Integer (PK) | Unique branch id |
| BranchName | Text | Display name (city + suffix) |
| City | Text | Branch city |
| Region | Text | North / South / West / East |
| OpenedYear | Integer | Year branch opened |

## DimProduct

| Column | Type | Description |
|---|---|---|
| Product | Text (PK) | Retail Banking, Corporate Banking, Wealth Management, SME Lending, Cards & Payments |

## DimDate (create in Power BI)

```dax
DimDate =
ADDCOLUMNS (
    CALENDAR ( DATE(2024,1,1), DATE(2026,6,30) ),
    "Year", YEAR ( [Date] ),
    "MonthNo", MONTH ( [Date] ),
    "MonthName", FORMAT ( [Date], "MMM" ),
    "YearMonth", FORMAT ( [Date], "YYYY-MM" ),
    "Quarter", "Q" & FORMAT ( [Date], "Q" )
)
```
Mark as date table on `[Date]`.
